U-Boat | CK My Apps

Upload all files in this folder into a GitHub Pages repository root. Enable Pages: Deploy from a branch / main / root. Open the published URL. No server, backend or dependencies required.

This is a fictional alternate-history tactical game inspired by Convoy (Creative Computing) using historical convoy names and date contexts. The U-667 historically did not serve from 1939 and tactical arrangements/outcomes in the game are fictional. Historical reference links are included in each mission.

Controls: touch arrows or map adjacent cells, keyboard arrow keys; P periscope; F toggle fire mode; choose an arrow for the fire direction. Save 4 local slots and autosave. Sound can be toggled in Settings.

Created by Christos A. Kazantzoglou | https://ckmyapps.substack.com/
